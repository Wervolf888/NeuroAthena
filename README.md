# НейроАфина

Сайт-каталог нейросетей для людей: все нейросети, все цены, все новости.

**Живой сайт: [neuroathena.pages.dev](https://neuroathena.pages.dev)**

Статический сайт (HTML/CSS/JS без сборки), хостинг — Cloudflare Pages из этого репозитория: каждый коммит в ветку main сам обновляет сайт. Данные лежат в папке data/ отдельными файлами и обновляются без переделки сайта.

## Что внутри

- 20 страниц: главная, 7 разделов каталога, цены, конвертер валют по курсу НБУ, акции, скидки, купоны, календарь акций, новости, календарь релизов, конструктор сравнений, бесплатное и пробы, рейтинги по задачам, выбор пользователей.
- Каталог — 59 моделей: цены с Украиной первой строкой, плюсы, минусы и подводные камни, языки интерфейса, оценки пользователей.
- Новости собираются автоматом каждое утро из официальных лент (GitHub Actions, scripts/update-news.mjs), включая русско- и украиноязычные источники.
- Ежедневная кураторская ротация: цены, ссылки и данные одной категории в день проверяются вручную.
- Вход через Google; избранное и выбор сравнения хранятся в браузере посетителя.
