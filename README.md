# НейроАтлас

Сайт-каталог нейросетей: все нейросети, все цены, все новости.

Статический сайт (HTML/CSS/JS без сборки), хостинг — Cloudflare Pages из этого репозитория.
Данные лежат в папке data/ отдельными файлами и обновляются куратором без переделки сайта.

Состояние: черновик этапа 1 (каркас и главная) — см. СОСТОЯНИЕ.txt.
Этапы: 1 каркас и главная; 2 категории и карточки; 3 цены и акции; 4 конструктор сравнений;
5 новости, календарь, выбор пользователей, рейтинги; 6 языки RU/EN/UK и вход Google; 7 финальная приёмка.
